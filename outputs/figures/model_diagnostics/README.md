# Model Diagnostics Figures Guide

이 폴더는 모델 성능 비교와 일반화 상태를 점검하기 위한 진단 그래프를 모아둔 곳입니다.  
주요 목적은 `MLP`, `LightGBM`, `SVM`의 성능 차이를 한눈에 비교하고, 어떤 모델이 더 안정적이고 설득력 있는지 설명하는 것입니다.

## 먼저 알아두면 좋은 해석 규칙

### 1. Accuracy / F1 비교 그래프

- 값이 높을수록 성능이 좋습니다.
- 이 프로젝트에서는 클래스 균형을 고려하기 위해 `F1-macro`를 특히 중요하게 봅니다.

### 2. Generalization gap

- validation 성능과 test 성능의 차이를 보는 그래프입니다.
- 차이가 작을수록 새로운 데이터에도 안정적으로 작동한다고 볼 수 있습니다.

### 3. 클래스별 지표 그래프

- 전체 평균 성능이 좋아도 특정 단계에서만 약할 수 있기 때문에 같이 봐야 합니다.
- 특히 2단계처럼 경계가 애매한 클래스에서 성능 저하가 나타날 수 있습니다.

## 그래프별 설명

### `01_overall_metric_comparison.png`

세 모델의 전체 성능 지표를 한 장에서 비교한 그래프입니다.

해석:

- Accuracy, F1-macro, F1-weighted 등을 함께 비교해 전체 우열을 판단할 수 있습니다.
- 발표에서는 "어떤 모델이 전체적으로 가장 안정적인가"를 설명할 때 첫 그림으로 쓰기 좋습니다.
- 이 프로젝트에서는 SVM이 가장 높은 전반 성능을 보이는 근거로 활용할 수 있습니다.

### `02_generalization_gap.png`

validation 성능과 test 성능 사이의 차이를 모델별로 비교한 그래프입니다.

해석:

- gap이 작을수록 과적합 위험이 낮고 일반화가 더 안정적입니다.
- validation에서만 높고 test에서 많이 떨어지는 모델은 실전 적용 신뢰도가 낮을 수 있습니다.
- 발표에서는 "성능이 높은 것뿐 아니라 얼마나 안정적인가"를 보여주는 보조 근거로 쓰기 좋습니다.

### `03_test_perclass_f1.png`

테스트셋 기준 클래스별 F1-score를 비교한 그래프입니다.

해석:

- 1단계, 2단계, 3단계 중 어느 단계에서 강하고 약한지 확인할 수 있습니다.
- 전체 F1가 높더라도 특정 단계에서만 낮으면 그 부분을 같이 설명해야 합니다.
- 특히 중간 단계인 2단계는 다른 단계와 경계가 겹치기 쉬워 상대적으로 어려운 클래스인지 점검할 수 있습니다.

### `04_test_perclass_recall.png`

테스트셋 기준 클래스별 recall을 비교한 그래프입니다.

해석:

- 실제 해당 단계인 사람을 얼마나 잘 찾아냈는지를 보여줍니다.
- recall이 낮으면 그 단계를 놓치는 경우가 많다는 뜻입니다.
- 정책 타깃 선별 관점에서는 recall 해석이 중요할 수 있어서, 단순 정확도 외 보조 지표로 설명하기 좋습니다.

### `05_improvement_summary.png`

모델 또는 실험 버전별 성능 개선 효과를 요약한 그래프입니다.

해석:

- baseline 대비 어떤 실험이 얼마나 성능을 끌어올렸는지 요약해서 보여줍니다.
- 발표에서는 "우리가 단순히 모델만 돌린 것이 아니라, 성능 개선 과정을 거쳤다"는 점을 보여주는 그림으로 활용할 수 있습니다.

### `06_svm_gridsearch_curve.png`

SVM의 `C` 하이퍼파라미터 탐색 결과를 보여주는 그래프입니다.

해석:

- 어떤 `C` 값에서 validation 성능이 가장 좋았는지 확인할 수 있습니다.
- 너무 작은 `C`나 너무 큰 `C`에서 성능이 떨어졌다면, 적절한 규제 강도의 중요성을 설명할 수 있습니다.
- 최종 SVM 선택이 임의가 아니라 탐색 결과에 근거한 것임을 보여주는 자료입니다.

### `07_lgbm_optuna_trials.png`

LightGBM의 Optuna 탐색 결과를 시각화한 그래프입니다.

해석:

- trial이 진행되며 어떤 성능 조합이 나왔는지 볼 수 있습니다.
- 최적 하이퍼파라미터가 탐색 과정에서 어떻게 선택되었는지 설명할 때 활용할 수 있습니다.
- 발표에서는 "자동 탐색을 통해 성능을 개선했다"는 근거 자료로 쓰면 좋습니다.

### `09_pca_stage_separation.png`

단계를 PCA 공간에 투영해 시각적으로 분리해 본 그래프입니다.

해석:

- 1단계, 2단계, 3단계가 저차원 공간에서도 어느 정도 구분되는지 직관적으로 볼 수 있습니다.
- 군집이 완전히 분리되어 있지 않더라도, 전반적 경향 차이가 존재한다는 보조 시각 자료로 사용할 수 있습니다.
- 단계 간 경계가 얼마나 자연스럽거나 겹치는지 설명할 때 유용합니다.

### `10_radar_stage_profile.png`

단계별 주요 영역 평균을 레이더 차트 형태로 비교한 그래프입니다.

해석:

- 각 단계가 어떤 역량/활동 프로파일을 가지는지 큰 그림으로 보여줍니다.
- 1단계는 전반적으로 낮고, 3단계는 전반적으로 높으며, 2단계는 중간적 성격을 보인다는 식의 설명에 적합합니다.
- 발표에서 단계 이름에 대한 직관적 근거를 보여주기 좋습니다.

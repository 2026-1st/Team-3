# 전처리 데이터 (Preprocessed Dataset)

한국지능정보사회진흥원(NIA)의 디지털정보격차 실태조사 데이터를 기반으로, 디지털 역량 수준 세분화 모델 학습을 위해 전처리를 수행한 데이터셋입니다.

## 데이터 개요
* **데이터 출처**: 한국지능정보사회진흥원(NIA) 디지털정보격차 실태조사 (2024~2025년)
* **대상 그룹**: 일반국민, 농어민, 장애인, 저소득층, 고령층 (총 5개 그룹)
  * *참고: 북한이탈주민과 결혼이민자는 데이터셋에서 제외됨*
* **목적**: 디지털 역량 수준 세분화 모델 학습을 위한 데이터 전처리 및 구축

---

## 제공 파일 목록
* `train.csv` / `전처리 train_set.xlsx`
* `val.csv` / `전처리 val_set.xlsx`
* `test.csv` / `전처리 test_set.xlsx`

> 💡 **안내**: `.xlsx` 원본 파일은 구글 드라이브를 통해 다운로드 가능합니다.

## 데이터 분할 및 구성 결과

### 1. 데이터셋 분할 요약
* **분할 비율**: Train 70% / Validation 15% / Test 15%
* **Stratify 기준**: `GROUP` 변수 (그룹별 데이터 비율을 모든 세트에서 동일하게 유지)
* **결측값**: 최종 전처리 결과 결측값 **0개** (완전 제거 또는 대체 완료)
